      The Modelling Approach: Knowing What to Measure Directly and What to Infer

      We call this Minimum Sufficient Fidelity: the model only represents what a decision actually depends on, not every last detail of the factory floor

      Line Topology & Operating Assumptions

      The operating assumptions below were chosen deliberately so the model generalizes across OEMs rather than being tuned to one factory's quirks

      🏭 35-Station Mixed-Model Line

      The line spans Body Construction (S1 to S10), the Paint Shop (S11 to S20), and Final Assembly (S21 to S35), and it was built to route EV, hybrid, and combustion variants down the same physical stations without anyone having to reconfigure anything by hand.

      ● Topology: 3 Zones / 35 Stations

      ⚖️ Uneven Sensor Coverage

      Roughly 68% of stations are well-instrumented with automated telemetry, while the remaining 32% are sensor-poor and depend on manual operator checks plus physics-informed or spatial estimation to fill the gap. That imbalance is realistic, and it's exactly the situation the model is designed to handle gracefully.

      ● Instrumented: 24 | Manual/Inferred: 11

      ⏱️ Maintenance Window Retrofits

      New non-invasive IoT sensing only goes in during the two scheduled shutdowns each year or during shift breaks shorter than 15 minutes, so instrumenting a sensor-poor station never costs the plant a minute of production time.

      ● Downtime Impact: 0 Hours

      📐 Physics-Informed (PINN)

      When a station has no working sensor, a physics-informed neural network fills the gap by simulating what the missing reading should look like, constrained by the actual physical equations that govern the process rather than a pure black-box guess.

      📊 Neighbor Interpolation

      For simpler parameters, we estimate a station's condition by weighting the readings from its instrumented neighbors, on the reasonable assumption that adjacent stations on the same line tend to drift in similar ways.

      📈 Statistical Estimation

      When neither physics nor neighboring sensors give us enough to work with, we fall back to historical distributions for that station, so the estimate is still grounded in what's actually happened there before rather than a flat default.

      🧮 Kalman Filter Fusion

      Where a station has a noisy or intermittent sensor rather than none at all, a Kalman filter blends the live but unreliable reading with the model's own prediction, weighting each side by how much it trusts it at that moment.

      Non-Invasive OT & Legacy PLC Integration

      We read from legacy operational technology, we never write to it, which means no production downtime and no changes to the plant's existing ladder logic

      🔌 Non-Intrusive Edge Tapping

      Passive OPC-UA and MQTT listeners simply poll the PLC's memory blocks from the outside, so timing-critical ladder loops keep running exactly as they always have. Because nothing about the control logic changes, there's no recertification to file and no shutdown required to install it.

      ● Edge Listener: ACTIVE (0.2ms latency)

      🧲 Low-Cost Retrofit Sensing

      For stations that genuinely have no usable signal, we retrofit with magnetic MEMS accelerometers, split-core current clamps that infer torque through an I²R proxy, and handheld IR guns for temperature. Each install takes under 15 minutes and needs nothing more invasive than a magnet or a clamp.

      ● Retrofits Deployed: 14 stations

      🛡️ OT/IT Air-Gap & Data Diode

      A one-way hardware data diode sits between the OT control network and the digital twin's cloud endpoints, so telemetry can flow out for analysis but nothing from the outside world can ever write back in.

      ● Security Diode: ENFORCED
