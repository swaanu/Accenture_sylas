## 📋 Pre-Recording Checklist & Hotkey Cheat Sheet

Before hitting Record on OBS / Screen Recorder:

1. **Start Python Server:**
   ```bash
   python server.py
   ```
2. **Browser Setup:**
   - Open Chrome / Edge in Fullscreen (`F11`) at `http://localhost:8080`.
   - Ensure browser zoom is at 100% and audio microphone levels are calibrated.
3. **Hotkeys to Use During Video:**
   - `Space`: Pause / Play simulation.
   - `1`: Jump to Floor Supervisor View (conveyor, topology, oscilloscope).
   - `2`: Jump to Modelling Approach View (PINNs, thermal-mechanical coupling).
   - `3`: Jump to Predictive Techniques View (SPC, CUSUM, EWMA, Isolation Forest).
   - `4`: Jump to Prescriptive Interventions (Monte Carlo sliders, OT safety gate).
   - `5`: Jump to Plant Manager View (shifting bottleneck migration matrix).
   - `6`: Jump to Executive Leadership View (multi-site comparison, THI, ROI).
   - `7`: Jump to Model Validation View (80/20 holdout metrics, confusion matrix).
   - `?`: Open keyboard shortcuts cheat sheet.
